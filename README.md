Supply Chain Analysis using SQL

Project Overview

This project analyzes supply chain operations using MySQL. It focuses on product revenue, inventory management, shipping costs, and delivery performance.

Project Objectives

- Analyze total orders and revenue.
- Identify delayed shipments.
- Calculate on-time delivery percentage.
- Identify products requiring inventory replenishment.
- Analyze revenue by product, category, customer, and city.
- Evaluate shipping costs and delivery time.

Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

Key Findings

- Total shipments: 6

Business Recommendations

- Monitor inventory and plan stock replenishment.
- Investigate delayed shipments.
- Track revenue by product and category.
- Monitor delivery performance regularly.
